365 DAYS OF US — DYNAMIC VERSION ♡

QUICK START
1. Extract this ZIP.
2. Open index.html in a browser to preview.
3. Open index.html in Notepad or VS Code to edit.
4. Replace the short [bracketed] prompts and captions. The sample anniversary note and reasons can also be edited.
5. Put your photos/screenshots in the images folder, then update the gallery image paths in index.html:
   src="images/your-photo.jpg"
6. Optional music: add a music.mp3 file beside index.html. The floating music button will play it after she taps it.

WHAT'S NEW
- Floating animated hearts in the background
- Envelope-opening intro
- Sparkles when she taps/clicks
- Sections fade in while scrolling
- Hover effects on photo cards
- Floating music toggle (optional music.mp3)
- Mobile-friendly layout
- Shorter sample wording and fewer fields

PUBLISH FREE
1. Go to https://app.netlify.com/drop
2. Drag the extracted 365-days-of-us-dynamic folder onto Netlify Drop.
3. Copy the public link Netlify gives you.
4. If you edit later, drag the updated folder again to redeploy.

Keep index.html, the images folder and optional music.mp3 together.
Only add photos and music you have permission to share.
